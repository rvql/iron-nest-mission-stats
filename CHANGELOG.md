# Changelog

All notable changes to MissionStats are documented here.

## [0.1.0] - 2026-09-02

### Added

- Live mission statistics for shots, hits, kills, requisition spending, timing, accuracy, and derived values.
- A mission medal panel with progress indicators for all four mission medals.
- Bronze, Silver, and Gold requirement tables shown when hovering over a medal summary.
- Correct display of calculated medal conditions, including localized formulas and their input statistics.
- Automatic localization of mission, medal, and statistic names based on the current game language.
- Configurable hotkeys, default panel visibility, dimensions, opacity, and refresh interval.
- Mission-only display behavior with no overlay outside an active mission.
- MelonLoader 0.7.3 support and Thunderstore packaging.
