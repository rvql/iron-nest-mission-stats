# MissionStats

[English](README.en.md)

## 简介

MissionStats 是用于 **IRON NEST: Heavy Turret Simulator** 的关卡统计插件。它会在游戏中实时展示当前关卡的统计数据与奖章要求，帮助玩家了解本局表现，并更方便地完成和收集关卡奖章。

![MissionStats 中文游戏截图](https://raw.githubusercontent.com/rvql/iron-nest-mission-stats/main/assets/screenshots/missionstats-zh.png)

## 功能

- 实时展示射击次数、命中、击杀、消耗等关卡数据。
- 展示当前关卡的奖章进度、达成条件及相关统计值。
- 任务名称、奖章名称和统计名称自动跟随游戏语言。
- 支持自定义快捷键、默认显示状态、面板尺寸与透明度。

## 安装方法

### r2modman

1. 在 r2modman 中选择 **IRON NEST: Heavy Turret Simulator**。
2. 在在线模组列表中搜索并安装 **MissionStats**。
3. 使用 **Start modded** 启动游戏。

### 手动安装

1. 安装 MelonLoader `0.7.3` 或兼容的 `0.7.x` 版本，然后启动并退出一次游戏。
2. 将 `MissionStats.dll` 放入 `<游戏目录>\Mods`。
3. 将 `MissionStats.Core.dll` 放入 `<游戏目录>\UserLibs`。
4. 正常启动游戏。
