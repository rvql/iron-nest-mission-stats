# MissionStats

[中文](README.md)

## About

MissionStats is a mission statistics plugin for **IRON NEST: Heavy Turret Simulator**. It displays live mission statistics and medal requirements in-game, making it easier to track progress and collect mission medals.

![MissionStats English in-game screenshot](https://raw.githubusercontent.com/rvql/iron-nest-mission-stats/main/assets/screenshots/missionstats-en.png)

## Features

- Displays live mission statistics such as shots, hits, kills, and requisition spending.
- Shows medal progress, requirements, and the related current statistics for the active mission.
- Follows the game's current language for mission, medal, and statistic names.
- Supports configurable hotkeys, default visibility, panel size, and opacity.

## Installation

### r2modman

1. Select **IRON NEST: Heavy Turret Simulator** in r2modman.
2. Search for and install **MissionStats** from the online catalog.
3. Start the game through r2modman.

### Manual installation

1. Install MelonLoader `0.7.3` or a compatible `0.7.x` version, then launch the game once.
2. Copy `MissionStats.dll` to `<Game directory>\Mods`.
3. Copy `MissionStats.Core.dll` to `<Game directory>\UserLibs`.
4. Start the game.
